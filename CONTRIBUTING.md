# Contributing to Forgit

Thanks for helping improve Forgit. Before opening a large pull request, start a
discussion so that implementation work is not wasted.

## Development

Use conventional commits and run the repository checks before submitting a
change:

```sh
pnpm install
pnpm check
```

## Contributor terms

Forgit is offered under both an open-source license and a commercial license.
The Computer Plumbers must have permission to distribute every contribution
under both models.

Before merging a contribution from an outside contributor, The Computer
Plumbers will ask that contributor to sign the
[Contributor License Agreement](CLA.md), which grants those rights while the
contributor keeps ownership of their work. Opening a pull request by itself
does not transfer copyright or grant commercial relicensing rights.

Contributors must have the right to submit their work and must identify code,
assets, or other material copied or adapted from another source.
